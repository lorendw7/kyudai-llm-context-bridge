# Security and sensitive data

This project is at the research-preparation stage. It does not currently provide a hosted LLM service, authentication system, or model API. The static website demonstration uses fixed synthetic text and makes no model calls.

Do not post credentials, private conversations, personal information, or exploitable security details in public issues. If GitHub private vulnerability reporting is enabled, use the repository's **Security → Report a vulnerability** form. Otherwise, open an issue requesting a private reporting channel without including sensitive details. No response-time guarantee is offered.

If a credential is accidentally exposed, revoke it with its issuer; deleting it from the latest file does not remove it from Git history. Never assume the ignore rules are a substitute for reviewing staged files and history.
