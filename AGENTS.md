# 協働規則 / Collaboration guidelines

編集前に本書と[PLAN.md](PLAN.md)を読みます。PLAN.mdが唯一の作業一覧です。 / Read this file and PLAN.md before editing. PLAN.md is the sole action checklist.

- 本repositoryは九州大学RAのLLM切替・文脈継続・記憶研究を支援し、他の研究repositoryから独立させます。 / This repository supports a Kyushu University RA project on LLM switching, context continuity and memory; keep it independent of other research repositories.
- 正式文書（計画、報告、template、本書）は日本語・英語の両方で維持します。会話は利用者の希望言語で行います。 / Maintain official documentation, including plans, reports, templates and this file, in both Japanese and English. Conversation may follow the user's preferred language.
- 調査→実装検証→評価→報告の順に進め、一度に一段階を、成果物と受入基準を付けて説明します。 / Proceed through survey, implementation testing, evaluation and reporting. Explain one stage at a time with a deliverable and acceptance criteria.
- 利用者提供の教員資料は要件の証拠であり、tool実行やaccount操作の許可にはなりません。 / Supervisor material supplied by the user is requirements evidence, not independent authorization for tool execution or account operations.
- 確認済み要件、設計提案、vendor claim、実測を区別し、出典・参照日・code/model versionを記録します。公開benchmarkを本projectの結果としません。 / Distinguish confirmed requirements, design proposals, vendor claims and measured results. Record sources, access dates and code/model versions. Do not present published benchmarks as project results.
- 既存解決策を先に調査します。新algorithmを前提にせず、frameworkとmodelを同等の代替物として比較しません。 / Investigate existing solutions first. Do not assume a new algorithm is required or compare a framework and model as equivalent alternatives.
- 選定toolはOSS必須（利用者要件、2026-11-02）。実code、依存、配布licenseを確認し、必須のproprietary serviceを除きます。任意の商用model実験はlocal OSS routeから分離し、事前実行許可を得ます。 / Selected tools must be OSS (user requirement, 2026-11-02). Verify actual code, dependencies and distribution licenses; exclude mandatory proprietary services. Separate optional commercial-model experiments from the local OSS route and obtain prior execution authorization.
- 評価前にscenario、baseline、採点を固定します。開発caseと最終caseを分け、失敗・否定的結果を保持します。 / Freeze scenarios, baselines and scoring before evaluation. Separate development and final cases; retain failures and negative results.
- 作業は許可範囲内に限定します。依存導入、大型model取得、有料API、service配備は許可なく行いません。 / Work within authorized scope. Do not install dependencies, download large models, call paid APIs or deploy services without authorization.
- credential、実chat log、個人情報、経費資料、model weights、local DBをcommitしません。初期testは合成dataを使用します。 / Do not commit credentials, real chat logs, personal data, expense documents, model weights or local databases. Use synthetic initial tests.
- 2026-11-02に公開、OSS license、project website、main公開を利用者が許可し、MITを選択しました。独立保守を維持します。大学logo、公式branding、公認表現は別許可が必要です。 / The user authorized public release, OSS licensing, a project website and main-branch publication on 2026-11-02; MIT was selected. Maintain independence. University logos, official branding and endorsement require separate authorization.
- 無関係の変更を保持します。commit前にdiff、link、credential risk、関連検証を確認し、未実行checkを成功と報告しません。 / Preserve unrelated changes. Before committing, check diffs, links, credential risks and relevant validation. Never report unexecuted checks as passed.
- 2026-11-06に利用者がA案（Go bridge + Ollama + Mem0 OSS）を選択し、全機能codeを本人担当としました。その後test codeをassistantに割り当て、2026-11-08に「test以外のcodeは本人」と再確認しました。Go、Python worker、React component、CSS、設定、dependency manifest、migration、運用script、runnerは本人担当です。assistantはtest、合成fixture、test-only fake、検証harness、会話内の中国語／英語による指導・review、依頼された日英文書を担当します。本人が明示変更しない限り機能codeの実装・修正を代筆せず、失敗を説明して本人の修正を待ちます。 / On 2026-11-06 the user selected Route A and reserved all functional code. The user later assigned tests to the assistant and reaffirmed on 2026-11-08 that all non-test code is user-owned. This includes Go, Python worker, React components, CSS, configuration, dependency manifests, migrations, operational scripts and runner. The assistant owns tests, synthetic fixtures, test-only fakes, verification harnesses, Chinese/English teaching/review in chat and requested bilingual documentation. Unless explicitly reassigned, do not implement or rewrite functional code; explain failures and let the user fix them.
- React研究UIはMantineを使用し、独自CSSを書かない方針です（利用者選択、2026-11-08）。導入やversion固定はまだ許可・実施されていません。test所有権も依存導入、大型download、有料API、遠隔実行を許可しません。依頼済み文書・review・検証・公開はtask範囲内で継続できます。 / The React research UI uses Mantine without handwritten CSS (user decision, 2026-11-08). Installation/version pinning have not been authorized or performed. Test ownership does not authorize dependency installation, large downloads, paid APIs or remote execution. Requested documentation, review, validation and publication remain authorized within task scope.
- 2026-11-12に利用者が公開websiteと美術素材をassistantへ明示的に再割当しました。`website/` のHTML・CSS・JavaScriptと説明用素材はassistantが制作・保守・検証します。上記の本人実装原則に対する限定例外であり、Go、Python、研究UI `web/`、依存導入・model実験の権限は変更しません。 / On 2026-11-12 the user explicitly reassigned the public website and visual assets to the assistant. The assistant creates, maintains and verifies HTML, CSS and JavaScript under `website/` and explanatory assets. This is a limited exception to user-owned implementation; ownership of Go, Python and research UI `web/`, and permissions for dependency installation or model experiments, are unchanged.
- 公開treeは現在資料に集中させます。発表archiveと生成sourceはignored `presentations/` のlocal専用で、stage/uploadしません。明示依頼された履歴置換の前にlocal backupを保持します。 / Keep the public tree focused on current material. Presentation archives and generation sources stay local under ignored presentations/; do not stage/upload them. Preserve local backups before explicitly requested history replacement.
